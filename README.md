1. SANAD AI CHAT

==================================================

The current app already has "سَنَد الذكي".

Upgrade this into a dedicated conversational AI experience.

Create a new screen:

"Sanad AI"

Subtitle:

"مساعدك المالي الذكي"

The screen should look like a premium banking AI assistant, NOT a generic ChatGPT clone.

At the top:

🧠 Sanad AI

"كيف أقدر أساعدك اليوم؟"

Show suggested questions as small chips:

"كيف أوصل لهدفي أسرع؟"

"وين أقدر أوفر؟"

"وش تأثير مصروفي على هدفي؟"

"كم أحتاج أدخر شهريًا؟"

When the user taps a suggestion, show a realistic simulated AI response based on their demo financial data.

Example:

User:

"كيف أوصل لهدفي أسرع؟"

SANAD AI:

"هدفك الحالي 12,000 ر.س، والمدخر حاليًا 8,400 ر.س.

إذا رفعت ادخارك الشهري من 600 إلى 750 ر.س، تقدر توصل لهدفك بشكل أسرع."

Then show:

[ عدّل خطتي ]

The button should navigate to the saving plan.

Also allow a text input at the bottom:

"اكتب سؤالك..."

and a send button.

The chat can use simulated responses.

IMPORTANT:

Make the AI contextual to SANAD's financial goal experience.

Do not make it a generic chatbot.

12. "DON'T TOUCH MY SAVINGS" 🔒

==================================================

Create a dedicated feature:

"لا تلمس مدخراتي"

This should be one of SANAD's signature features.

Purpose:

Help the customer understand the financial impact of withdrawing money from a saving goal.

Do NOT block the user from accessing their money.

When the user tries to withdraw from their goal, show a beautiful confirmation sheet.

Example:

"لحظة..."

"سحب 500 ر.س من مدخراتك قد يؤخر وصولك لهدفك."

Show:

قبل السحب

الوصول المتوقع:

أبريل 2027

بعد السحب

الوصول المتوقع:

مايو 2027

"قد يتأخر هدفك 24 يومًا."

Buttons:

"أبقي مدخراتي"

"اسحب على أي حال"

Both buttons must work.

If the user chooses "أبقي مدخراتي":

Close the sheet and keep the goal unchanged.

If the user chooses "اسحب على أي حال":

Simulate the withdrawal and update the goal progress.
